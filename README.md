# $\textsf{Thimza}$

As a post-quantum threshold signature scheme, $\textsf{Thimza}$ is a threshold system from lattices. This repo contains $\textsf{Thimza}$'s **(i)[core implementation](#core-implementation)** for evaluation and **(ii)construction specifications**, along with its **(iii)machine-checked proofs**. As this is an ongoing initiative, the detailes of both codes and [EasyCrypt](https://link.springer.com/chapter/10.1007/978-3-642-22792-9_5) proofs are being updated and evolving.
